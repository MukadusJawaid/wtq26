# WTQ 2026 Build Track: Utility Bill Decoder — rules we follow

Source: `docs/WTQ_Build_Track_Participant_Guide.pdf` and the event slides.

## Schedule
- 10:30 AM: 5 train bills (`train/bills`), no answers. Set up API key.
- 12:30 PM: 10 test bills + `level1.csv` / `level2.csv` templates.
- **Submit once, before 1:30 PM**, at https://build.womentechquest.com/submit (same email as WTQ registration). No re-submission.

## Levels (both required)
- **Level 1 Extract** (30 marks): one JSON object per bill -> `level1.csv` (`bill_id,json`, 10 rows).
- **Level 2 Explain** (30 marks): same 12 questions per bill -> `level2.csv` (`bill_id,question_id,question,answer`, 120 rows).
- Engineering quality 15, AI design 15, completeness/reproducibility 10, demo bonus 5.

## Level 1 rules
- Include every schema field, use `null` when not printed/covered/unreadable (don't guess); `[]` for empty lists.
- Values **as printed**: no recalculating/rounding. Numbers are PKR, no commas/currency. Credits/subsidies negative (`38209CR` -> `-38209`).
- Dates `YYYY-MM-DD`; `bill_month` `YYYY-MM`. Provider is `KE | LESCO | IESCO` (file prefix KESC = KE).
- Charge types: energy, fixed, fpa, quarterly_adjustment, surcharge, meter_rent, subsidy, other. Skip blank/0 lines; keep repeated types separate.
- Tax types: gst, electricity_duty, income_tax, municipal_tax, other_tax. Classify by printed section. Combined tax only -> `taxes: []` and set `total_taxes`.
- `payable_after_due_date`: if several, use the highest. Totals are the printed subtotals (null if none).
- **No personal identifiers** (names, addresses, CNIC, account/reference/consumer/meter numbers).
- Each JSON on one line in the CSV cell, quotes doubled (use a CSV library).

## Level 2 rules
- English only, grounded in the bill only (no outside tariff info); say so when the bill lacks a value.
- Compute numbers with code; label estimates and show how; state the interpretation for ambiguous questions.
- No personal identifiers.

## House rules
- **Only approved models:** Claude Haiku 4.5 (`claude-haiku-4-5`), Gemini 3.5 Flash-Lite (`gemini-3.5-flash-lite`), Gemini 3.1 Flash-Lite (`gemini-3.1-flash-lite`), GPT-4.1 mini (`gpt-4.1-mini`), GPT-5 mini (`gpt-5-mini`). Anything else = disqualification.
- Local OCR (Tesseract, PaddleOCR) allowed. **Banned:** Azure prebuilt-invoice, Textract AnalyzeExpense, Mindee, Veryfi, "chat with your PDF" tools.
- **No hard-coded answers**; no test-bill values in code/data; don't hand-edit CSVs. Both CSVs must be generated by code.
- No copying between teams.
- Declare every model, service, framework and AI tool in the README (must match code).

## Submission ZIP (<= 15 MB)
```
your-submission.zip
  output/level1.csv, level2.csv
  source/README.md, .env.example, package.json + package-lock.json, ...code
  demo/demo.mp4   (optional, <= 3 min, +5 bonus)
```
- Node.js 22+ (state version in README). No `.env`, no API keys.
- README: setup, exact run command on a folder of bills, AI usage section ("none" where unused).
- `.env.example` with real non-secret values (provider, model name); recommended vars: `MODEL_PROVIDER`, `MODEL_NAME`, `API_KEY`.
- Demo should show: start, upload/select a bill, Level 1 fields, a few Level 2 answers, generation of both CSVs.
